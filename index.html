Режим заучивания

Изучай по одному имени: произноси, вспоминай смысл и повторяй.

Как заниматься

1. Прочитай арабское написание и произношение.
2. Повтори значение вслух.
3. Прочитай объяснение и перескажи его своими словами.
4. Отметь имя выученным, когда сможешь вспомнить его без подсказки.

Маленькие шаги

Начни с 3–5 имён в день. Возвращайся к ним через день, неделю и месяц. Регулярное повторение помогает удерживать знания.

Ссылка на опубликованный сайт

Сначала размести сайт на хостинге, затем вставь сюда полученную публичную ссылку.

Важно: QR-код сам по себе не публикует сайт. Пока сайт открыт только как локальный файл на ноутбуке, другие люди не смогут открыть его по QR-коду. Нужен публичный URL.

Как опубликовать

1. Распакуй ZIP-файл.
2. Загрузи index.html в статический хостинг, например GitHub Pages или Netlify.
3. Скопируй публичную HTTPS-ссылку и вставь её выше.
4. Создай QR-код и проверь его камерой телефона.
